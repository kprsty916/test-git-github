Belajar Git & Github

Berikut adalah daftar lengkap perintah-perintah Git yang paling sering digunakan dalam pengembangan perangkat lunak, dikelompokkan berdasarkan fungsinya beserta penjelasannya:

  • git init

    • Membuat repositori Git baru di dalam folder lokal yang sedang dibuka.

  • git add

    • Menambahkan file tertentu ke staging area (siap untuk di-commit).

  • git commit -m "pesan commit"

    • Menyimpan perubahan yang ada di staging area ke dalam riwayat Git beserta pesan penjelasannya.

  • git commit -am "pesan commit"

    • Menyimpan perubahan yang pernah dirubah dan ada di staging area ke dalam riwayat Git beserta pesan penjelasannya.
